DronePatrol 1.0.6 — исправление ошибочных отступов.

Это исправление сделано на основе присланного DronePatrol.rar.
Файл scripts/game.gd восстановлен по строкам: 64 строки с TAB заменены корректными пробельными отступами.
Старый кэш .godot не включён.

1. Закройте Godot.
2. Распакуйте эту сборку в НОВУЮ папку.
3. В менеджере Godot выберите Импорт и файл project.godot из этой папки.
4. Дождитесь импорта и откройте проект.
