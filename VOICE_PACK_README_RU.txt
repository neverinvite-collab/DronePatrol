Голоса DronePatrol v1.1.0

Настройки: голос генерала Oleksa / Mykyta, переключатель голосов врагов.
Голоса не входят в ZIP: генератор создаёт их на Windows.
Для первого запуска: Python 3, интернет, GENERATE_GAME_VOICES.bat.
Генерируются украинские WAV в assets/voices_v2/oleksa, mykyta, enemies.
Если генератор не запущен, новые голоса не будут звучать: старые неразборчивые голоса намеренно не используются.

Выбор голоса влияет на украинскую озвучку; для русского и английского нужны отдельные локализованные записи.

Модели Piper: rhasspy/piper-voices, убедитесь в соблюдении лицензий на конкретные модели при публикации.
