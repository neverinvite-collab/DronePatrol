DRONE PATROL - NEW VOICE SYSTEM (TEST)

IMPORTANT: Archive does not yet contain Piper generated voices because model downloads were unavailable in the build environment. The old WAV clips are placeholders.

On Windows:
1) Install Python 3.10-3.12 (Add Python to PATH / Python launcher).
2) Run GENERATE_UK_VOICES.bat once (internet required; ~340 MB downloads).
3) Check assets/voices/uk_*.wav modified.
4) Open project.godot in Godot 4.5+, wait for import, run.

Characters: Oleksa = General; Mykyta = soldier; Tetiana = dispatcher.
The game never calls Windows/Android native TTS. RU/EN clips remain existing audio.
Models: https://huggingface.co/rhasspy/piper-voices (Apache-2.0 on model cards; check individual models before distributing).
